# 포트폴리오 검토용 시각 자료

미게시 검토 자료다. 공개 사이트의 src/public이나 배포에는 반영하지 않았다.

## 구성

- 풍력: 평가 방식별 NMAE, 날짜 그룹 fold별 NMAE
- 데이터센터: 용량별 입지·송전 지표, 잔여부하와 풍력의 기간 에너지 수지
- KAMP: 20회 반복 오경보율, 이상 17개 중 경보·보류 구성
- 분석 흐름도 3개는 검토 Markdown/HTML의 반응형 목록으로 구현했다. 구현을 요약한 개념도이며 관측치 그래프가 아니다.

그래프별 SVG·PNG·표시 데이터 CSV가 있다. 출처 경로와 원본 해시는 chart-data.json에 기록했다.
재생성은 기존 Python 환경의 matplotlib/numpy와 NotoSansCJK 글꼴을 사용하는 build_charts.py로 수행한다. 모델을 재학습하거나 원본 결과 파일을 수정하지 않는다.

## 확인

- 원본 노트북 저장 출력과 CSV에서 값을 읽고 핵심 수치·행 수·분모를 assert로 점검했다.
- 오차·거리·에너지 막대축은 0에서 시작한다. 서로 다른 단위의 입지 지표는 독립 축으로 분리했다.
- KAMP의 표준편차를 신뢰구간으로 사용하지 않았다. 판정 보류는 평가 분모에 유지했다.
- 6개 PNG를 모두 열어 확인했고, 겹친 주석과 수치 라벨을 고친 후 해당 그림을 다시 확인했다.
- 링크·이미지·CSV 파일 존재와 이미지 대체텍스트를 검사했다.
- HTML은 좁은 화면에서 차트를 좌우로 이동하고 원본 확대를 제공하도록 구성했다. 실제 브라우저의 모바일 화면 검증은 하지 못했다.
