**React, TypeScript, Supabase · 모바일 우선 개인용 웹앱**

## 사용자 흐름과 상태 모델

두 사람이 가고 싶은 장소를 기록하고, 만날 수 있는 날짜를 맞춘 뒤, 확정한 일정을 사진과 후기로 이어 남기는 앱을 만들었습니다. 위시·확정·완료를 한 기록의 상태 변화로 보고, 홈의 날짜 카운트와 다음 일정, 달력·시간대별 계획·추억 화면을 연결했습니다. 공개 커뮤니티보다 소수 사용자의 공유 데이터가 맞는지에 집중한 제품입니다.

## 날짜·사진·저장 처리

설계 문서뿐 아니라 화면 컴포넌트와 데이터 접근 코드, Supabase 스키마·추가 마이그레이션이 있습니다. 날짜는 로컬 날짜 문자열로 계산해 자정과 UTC 변환 때문에 하루가 어긋나는 문제를 피하고, 시작·종료일과 사진 입력을 검증하는 순수 함수를 분리했습니다. 사진은 비공개 저장소와 signed URL을 사용하고, 업로드와 DB 기록 중간에 실패하면 고아 파일이 남는 문제를 다루도록 구현했습니다.

## 운영 확인과 공개 범위

로그인과 행 단위 접근 정책은 코드·SQL의 설계와 구현 범위입니다. 실제 운영 서버에서 두 계정만 접근한다는 정책을 이번에 재검증하지 않았으므로 보안 인증 성과로 제시하지 않습니다. 포트폴리오에는 관계·장소·사진·실제 일정 대신 사용자 흐름과 상태 모델만 설명하고, 기존 이미지의 사용 권리가 확인되기 전에는 해당 화면을 공개하지 않습니다.
