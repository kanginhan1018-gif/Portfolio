## 활동 로그와 웹 포트폴리오

활동을 나중에 다시 설명할 수 있도록 별도 기록에는 날짜·무슨 일·배경·수치·공개 상태를 적는 로그와 포스팅 가이드를 만들었습니다. 포트폴리오 사이트도 Markdown 사례, 논문 리뷰, 데이터 차트, 다국어와 배포 경로 검사로 구성했습니다. 게시 초안이나 템플릿을 실제 외부 발행과 같은 활동으로 세지 않고, 활동별 상세 페이지와 분야별 목록은 각 기록을 연결해 보여주는 역할을 합니다.

## 기록과 공개 상태의 구분

날짜와 배경, 결과 수치와 출처를 별도로 기록하고, 발표자료를 만들기 전에도 어떤 판단을 했는지 남길 수 있도록 구성했습니다. 공개한 사례와 학습 초안, 진행 중인 실험을 같은 완료 상태로 취급하지 않습니다.
