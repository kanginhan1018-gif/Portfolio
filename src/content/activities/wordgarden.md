## 어휘 기록과 데이터 단위

영어 단어나 숙어를 검색하면 영어 설명과 한국어 뜻을 함께 기록하고, 그날 찾은 표현으로 복습 문장과 퀴즈를 만드는 WordGarden을 개발했습니다. 사전의 두 언어 항목을 일대일 번역으로 가정하지 않고, 한쪽이 없거나 조회에 실패한 상태도 표시합니다. 같은 날 재검색은 횟수로 누적하고 다른 날에는 별도 기록으로 남기도록 데이터 단위를 정했습니다.

## 복습 생성과 실패시 보존

복습 생성은 로컬 Codex CLI를 사용하고, 실제 검색한 단어가 결과에 포함됐는지와 JSON 구조를 검사합니다. 이미 생성한 문장은 캐시하고 단어가 추가됐을 때만 재생성하며, 생성에 실패하면 기존 문장을 보존합니다. 뜻이 겹치는 선택지를 오답으로 쓰지 않는 퀴즈와 브라우저 음성 재생, 기록 내보내기·날짜별 삭제도 구성했습니다.

## 개인 클라우드로의 이전

처음에는 로컬 SQLite로 시작했고 이후 개인 계정만 접근하는 클라우드 Worker·R2로 단어장과 복습 결과를 옮겼습니다. 조건부 쓰기로 갱신 손실을 막고, 브라우저 사용자의 요청과 로컬 브리지의 작업 요청을 구분했습니다. 로컬 기록 4개 이전과 익명 요청 차단 확인이 문서에 남아 있습니다. 개인 단어장이나 비공개 접속 주소를 방문자의 데모 계정으로 공개하지 않습니다.

## 생성 작업과 운영 제약

클라우드 단어장과 생성 작업의 위치가 다르다는 제약도 설명했습니다. 복습 생성에는 컴퓨터에서 브리지가 실행 중이어야 하고 구독 사용 한도를 소비합니다. 무제한 무료 AI 서비스로 표현하지 않았으며, 실제 브라우저 종단 검증을 완료하지 못한 범위와 네트워크 실패시 동작을 기록했습니다.
