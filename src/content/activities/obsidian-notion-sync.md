**Python, Markdown 파싱, Notion API · 개인 지식관리 자동화**

## 노트 파싱과 분류

데일리 노트에서 제목·종류·하위 태그·본문을 나누고 Notion의 속성과 본문으로 옮기는 동기화 스크립트를 작성했습니다. 두 버전의 스크립트는 여러 DB로 태그별 분배하는 방식과 하나의 통합 DB에 종류·태그를 두는 방식을 각각 다룹니다. 원문 링크와 노트 경로도 함께 연결하도록 구성했습니다.

## 페이지 관계를 잇는 2단계 처리

페이지를 생성하면서 본문 안의 링크를 바로 찾으면 대상 페이지가 아직 없을 수 있어, 먼저 모든 제목과 페이지 ID를 수집하고 두 번째 단계에서 `[[문서 링크]]`를 페이지 언급과 관계형 속성으로 바꾸는 2단계 처리를 사용했습니다. 어제 날짜의 노트를 대상으로 하고 파일이나 파싱 대상이 없을 때 상태를 남기는 실행 스크립트도 있습니다.

## 구현 범위와 복구 과제

이는 노트 분류와 연결을 자동화한 구현 기록입니다. 모든 재실행의 멱등성이나 대규모 본문 길이, API 실패 후 복구를 보장한 동기화 엔진으로 설명하지 않습니다. 개인 보관함과 외부 서비스의 인증 설정은 공개 자료에서 제외하고, 재실행·실패 복구의 한계와 구현 범위를 중심으로 정리했습니다.
