이 글의 중심은 Achterberg, Bixby, Gu, Rothberg, Weninger의 *Presolve Reductions in Mixed Integer Programming* (ZIB Report 16-44) 7.1절(대칭 변수 병합)과 8.2절(orbital fixing)입니다. 두 절은 전문을 읽었습니다. orbital fixing을 처음 제안한 Margot의 논문(*Exploiting orbits in symmetric ILP*, Math. Programming 98, 2003)은 **무료 전문을 구하지 못해 읽지 못했고**, SCIP 문서와 Presolve 논문의 인용으로만 확인했습니다. 제가 만든 예시와 계산에는 그렇게 표시했습니다.

## 1. 대칭이 왜 문제인가

대칭이란, 변수(열)와 제약(행)의 이름을 바꿔 쓰면 같은 문제가 되는 구조입니다. 논문 8.2절은 이렇게 설명합니다.

> 많은 MIP 인스턴스에는 대칭이 있어서, 어떤 실행가능해에 대해서도 목적값이 같고 행렬의 열과 행 인덱스를 치환해서 얻는 다른 해가 존재합니다. 이 대칭은 탐색 트리에 대칭인 복사본 부분 문제를 만들고, 그 각각이 서로 동등한 해를 담고 있어서 풀이를 크게 방해할 수 있습니다.

**제가 만든 설명 예.** 같은 크기의 상자 $k$개에 물건을 나누어 넣는 문제에서는 "상자 1에 A, 상자 2에 B"와 "상자 1에 B, 상자 2에 A"가 이름만 다른 같은 해입니다. 상자가 $k$개면 같은 배치가 $k!$ 가지 이름 붙이기로 나타나고, 분지한계법은 이 복사본들을 각각 따로 탐색합니다. 이 글의 나머지는 논문이 이것을 어떻게 다루는지입니다.

대칭을 다루는 방법으로 논문은 Margot의 서베이와 Pfetsch–Rehn의 계산 비교 연구를 인용하고, 자기들이 쓰는 두 가지를 설명합니다.

## 2. 대칭의 정의 (Definition 7)

인덱스 집합 $N$의 치환 $\pi:N\to N$ 이 다음을 만족하면 **대칭 생성원(symmetry generator)** 입니다.

1. $c_j=c_{\pi(j)}$, $\ell_j=\ell_{\pi(j)}$, $u_j=u_{\pi(j)}$ 이고, $j\in I\Leftrightarrow\pi(j)\in I$ (목적계수, 경계, 정수성이 같다).
2. 행의 치환 $\sigma$ 가 있어서 $b_i=b_{\sigma(i)}$, $\circ_i=\circ_{\sigma(i)}$, $A_{\sigma(i)\pi(j)}=A_{ij}$ (열을 $\pi$ 로, 행을 $\sigma$ 로 바꾸면 원래의 제약 행렬이 된다).

추가로 두 종류가 있습니다.

- **비중첩(non-overlapping) 생성원**: $\pi(j)\ne j$ 인 모든 $j$ 에서 열 $A_{\cdot j}$ 와 $A_{\cdot\pi(j)}$ 의 비영 행이 겹치지 않습니다. 즉 $j$ 와 $\pi(j)$ 가 같은 행에 함께 나오지 않습니다.
- **연속변수 생성원**: $\pi(j)\ne j$ 인 모든 $j$ 가 연속변수입니다.

Gurobi는 Saucy(Darga 외)의 아이디어를 바탕으로 한 알고리즘으로 대칭을 탐지합니다.

## 3. 대칭 변수 병합 (7.1절)

**비중첩 대칭 생성원 $\pi$ 가 있으면 $x_j:=x_{\pi(j)}$ 로 변수를 합칠 수 있습니다.** 변수가 정수든 아니든 상관없습니다. 같은 궤도(orbit)에 있는 변수는 모두 하나의 변수로 합쳐집니다. 연속변수 생성원이면 합친 변수는 궤도 변수들의 산술평균에 해당합니다. 정수 변수에서는 평균이 정수성을 깨므로 이런 병합은 불가능합니다.

### 논문의 Example 9

모든 변수가 이진인 문제입니다.

$$\max\ 4x_1+4x_2+2x_3+2x_4+3x_5+4x_6+5x_7$$

$$
\begin{aligned}
x_1\ \ \ \ \ \ \ \ \ \ +4x_3\ \ \ \ \ \ \ \ \ \ +x_5+3x_6+2x_7&\le 8\\
x_2\ \ \ \ \ \ \ \ \ \ +4x_4\ \ \ \ \ \ \ \ \ \ +x_5+3x_6+2x_7&\le 8
\end{aligned}
$$

$\pi=(1\leftrightarrow2;\ 3\leftrightarrow4)$ 로 $x_1$과 $x_2$, $x_3$과 $x_4$ 를 바꾸고 두 행도 바꾸면 원래의 시스템이 됩니다. 또 $x_1,x_2$ 는 같은 행에 나오지 않고 $x_3,x_4$ 도 마찬가지이므로 **비중첩**입니다. 그래서 $x_2:=x_1$, $x_4:=x_3$ 으로 합치면

$$
\max\ 8x_1+4x_3+3x_5+4x_6+5x_7\quad\text{s.t.}\quad
\begin{cases}
x_1+4x_3+x_5+3x_6+2x_7\le 8\\
x_1+4x_3+x_5+3x_6+2x_7\le 8
\end{cases}
$$

이 되고, 두 제약이 같아져서 5.2절의 **평행 행 검출**이 하나를 지웁니다. 변수는 7개에서 5개로, 제약은 2개에서 1개로 줄었습니다.

**제가 직접 확인한 계산.** 두 문제를 모두 전수 열거해 보면 최적값이 같습니다. 원래 문제(변수 7개 이진)의 최적값은 20이고 최적해는 $(x_1,\dots,x_7)=(1,1,0,0,1,1,1)$ 과 $(1,1,1,1,1,0,1)$ 두 개입니다. 병합한 문제의 최적값도 20이고 최적해는 $(x_1,x_3,x_5,x_6,x_7)=(1,0,1,1,1)$, $(1,1,1,0,1)$ 로, 위 두 해와 정확히 대응합니다. 논문이 병합이 일반적으로 유효한 이유를 설명하는 증명은 이 글에서 따로 확인하지 않았습니다.

### 효과 (Table 28)

대칭 변수 병합을 끈 실험입니다.

| 구간 | 전체 모델 시간 배수 | 영향받은 모델 | 영향받은 모델의 시간 배수 |
|---|---|---|---|
| 10초 이상 | 1.03 | 130 | 1.36 |
| 100초 이상 | 1.06 | 88 | 1.50 |
| 1,000초 이상 | 1.16 | 41 | 1.84 |

전체로는 3%이지만 해당되는 약 10%의 모델에서는 상당한 개선입니다. 논문은 "대칭을 이용하는 reduction의 전형적인 모습"이라고 요약합니다. 적용되는 모델이 적지만 적용되면 매우 중요하다는 뜻입니다.

## 4. Orbital fixing (8.2절)

### 아이디어

분지한계 트리의 노드에서는 분지 결정과 노드 presolve로 변수 경계 $\bar\ell\le x\le\bar u$ 가 정해져 있습니다. 이 노드의 부분 문제에도 대칭이 남아 있을 수 있습니다. 그 대칭군이 변수 궤도 $\mathcal{O}$ 를 만들 때, 궤도 $O$ 안의 변수는 **모두 같은 상한을 가질 수 있습니다.** 논문의 식은 다음과 같습니다.

$$x_j\le\min\{\bar u_k:\ k\in O\}\qquad\forall j\in O$$

한 변수의 상한이 다른 궤도 구성원의 상한보다 낮으면 그 낮은 값으로 전체를 낮춥니다. 대칭인 변수들은 서로 바꿔 쓸 수 있어서 한 변수에서 알게 된 경계가 다른 변수에도 유효하기 때문입니다. 하한도 같은 방식으로 올릴 수 있지만 지역 경계 변경의 **출처를 추적해야 해서** Gurobi에는 구현돼 있지 않다고 합니다. 이 기법은 Margot가 도입했고 Ostrowski의 연구도 참고로 인용됩니다.

### 구현에서의 어려움: 지역 대칭군

Gurobi는 루트 노드에서 전역 문제 $P$ 의 대칭군 $G$ 를 Saucy 기반 알고리즘으로 구하고 생성원 집합으로 저장합니다. 문제는 **지역 노드에서 유효한 대칭군**입니다.

- 보통은 생성원을 걸러서, 지역 하한 $\bar\ell$ 에서 더는 유효하지 않은 것을 버리고 남은 것으로 지역에서 유효한 궤도를 구합니다. 계산이 싸지만, 분지로 **새로 생긴 대칭**을 이용하지 못하고, 부분적으로는 아직 유효한 궤도도 버립니다.
- 대안은 **노드마다 지역 대칭군을 처음부터 다시 계산**하는 것입니다. 아주 오래 걸리지만 특정 대칭 구조를 가진 모델에서는 이득이 있어서, 그런 구조가 탐지되면 Gurobi 기본 설정에서 켜집니다.

### 효과 (Table 36)

orbital fixing을 끈 실험입니다.

| 구간 | 전체 모델 시간 배수 | 노드 수 배수 | 영향받은 모델 | 영향받은 모델의 시간 배수 |
|---|---|---|---|---|
| 10초 이상 | 1.20 | 1.27 | 392 | **1.77** |
| 100초 이상 | 1.36 | 1.48 | 259 | 2.22 |
| 1,000초 이상 | 2.18 | 2.60 | 129 | 3.67 |

- 모델의 약 20%에 적용되고, 그 모델들에서 10초 이상 구간 기준 시간이 77% 늘어납니다.
- 끄면 시간 제한에 걸리는 모델이 37개 늘어납니다.
- 1,000초 이상 걸리는 어려운 모델에서 효과가 가장 큽니다. 전체 평균이 2.18배, 영향받은 모델에서는 3.67배입니다.

## 5. 모델 쪽에서 할 수 있는 것

논문에 있는 내용은 솔버가 자동으로 하는 reduction이고, 아래는 제가 정리한 일반적인 방향입니다.

- **동일한 기계, 차량, 시설이 여럿인 모델**을 쓸 때는 대칭이 생깁니다. 모델에 부하나 순서를 강제하는 제약(예: 기계 1의 부하 ≥ 기계 2의 부하 ≥ …)을 직접 넣는 방법이 있습니다. 이 방법의 효과는 이 글에서 다룬 논문들에서 측정되지 않았습니다.
- 위 예(Example 9)처럼 **같은 제약 구조를 가진 변수 쌍**이 있으면 솔버가 병합할 수 있으니, 모델을 만들 때 이런 구조가 우연히 숨어 있는지 의식해 볼 만합니다.
- 대칭이 없는 모델에서는 이 기법들이 아무 효과가 없습니다.

## 6. 한계

- Margot(2003)를 읽지 못했습니다. orbital fixing의 이론적 보증이나 isomorphism pruning의 세부는 이 글에서 다루지 못했습니다. SCIP 문서에 따르면 SCIP의 orbital fixing은 고정된 변수들의 안정화 부분군에 대한 궤도를 계산하고 **이진 변수에서만** 작동합니다. 이는 문서의 설명을 옮긴 것이고 직접 확인한 것이 아닙니다.
- 수치는 Gurobi 6.5와 저자들의 모델 세트 기준입니다.
- Example 9의 최적값 확인은 제가 한 전수 열거이고, 논문의 내용이 아닙니다.
