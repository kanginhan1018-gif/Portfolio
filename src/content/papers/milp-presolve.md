이 글은 Achterberg, Bixby, Gu, Rothberg, Weninger의 *Presolve Reductions in Mixed Integer Programming* 을 읽고 정리한 것입니다. 읽은 판본은 2016년 ZIB 프리프린트(ZIB Report 16-44, Gurobi 6.5 기준)이고, 2019년 INFORMS Journal on Computing 최종본과 세부가 다를 수 있습니다. 식과 예제, 표의 숫자는 전부 이 판본에서 가져왔고, 제가 직접 만든 숫자 예시에는 그렇게 표시했습니다.

## 1. presolve는 얼마나 중요한가

presolve는 솔버가 본격적으로 풀기 전에 모델에서 불필요한 것을 지우고 정식화를 강하게 만드는 전처리 루틴의 모음입니다. 논문은 이 효과를 Gurobi 소스 코드를 고쳐서 presolve를 끈 버전과 기본 설정 버전을 같은 문제 세트(3,182개 모델)에서 비교해 보여 줍니다. 시간 제한은 3,600초입니다.

| 구간 (풀이 시간) | 모델 수 | presolve를 끄면 시간이 늘어난 배수 | 노드 수 배수 |
|---|---|---|---|
| 전체 | 3,047 | 3.36 | 1.27 |
| 10초 이상 | 1,575 | 9.05 | 2.29 |
| 100초 이상 | 1,099 | 12.36 | 2.43 |
| 1,000초 이상 | 692 | 19.48 | 2.17 |

- 시간 제한에 걸린 모델은 547개에서 1,035개로 **488개 늘어납니다.
- 비교 대상은 shifted geometric mean(shift 1초)의 비입니다. 이 지표는 [분지 규칙 글](../milp-branching/)에서도 씁니다.
- 변수 경계만으로도 redundant 행을 찾을 수 있는 모델이 3,182개 중 2,525개입니다.
- 논문은 presolve를 두 단계로 나눕니다. **root presolve**는 첫 LP를 풀기 전에, **node presolve**는 분지한계 트리의 노드마다 추가로 적용합니다.
- 기법은 30개 이상이고 6개 그룹입니다. 단일 제약, 단일 변수, 다중 제약, 다중 변수, 전체 문제, 노드 presolve 순서입니다. 이 글은 그중 앞의 두 그룹과 일부를 다룹니다.

## 2. 기호

논문은 MIP를 이렇게 씁니다.

$$\min\; c^\top x \quad \text{s.t.}\; Ax \circ b,\;\; \ell \le x \le u,\;\; x_j \in \mathbb{Z}\;(j \in I)$$

여기서 $\circ_i$ 는 각 행의 관계($=$, $\le$, $\ge$)입니다. 변수 경계 $\ell, u$ 가 **무한대**일 수도 있습니다.

행 $i$의 좌변이 변수 경계 안에서 가질 수 있는 최솟값과 최댓값을 **활동량(activity)** 이라고 하고 다음과 같이 정의합니다(식 2.2, 2.3).

$$
\inf\{A_{i\cdot}x\}=\sum_{a_{ij}>0}a_{ij}\ell_j+\sum_{a_{ij}<0}a_{ij}u_j,\qquad
\sup\{A_{i\cdot}x\}=\sum_{a_{ij}>0}a_{ij}u_j+\sum_{a_{ij}<0}a_{ij}\ell_j
$$

계수가 양수인 항은 경계의 작은 쪽(큰 쪽)으로, 음수인 항은 반대쪽으로 놓으면 최솟값(최댓값)이 됩니다. 이 두 값이 아래 모든 기법의 재료입니다.

## 3. redundant 제약 (3.1절, 5.1절)

### 정의

> 제약 $r$을 지워도 MIP의 해 집합이 그대로이면 $r$은 redundant이다. ($P_{MIP}=P_{MIP_r}$)

### 가장 흔한 판정: 단일 제약 + 변수 경계

$\le$ 형태의 행에 대해 논문은 이렇게 처리합니다(허용오차 $\varepsilon$ 기본값 $10^{-6}$).

- $\sup\{A_{i\cdot}x\} \le b_i + \varepsilon$ 이면 이 행을 **삭제**합니다.
- $\inf\{A_{i\cdot}x\} > b_i + \varepsilon$ 이면 모델이 **비실현**입니다.

**직접 만든 숫자 예.** $x_1 + 2x_2 \le 10$, $0\le x_1\le 3$, $0\le x_2\le 2$ 이면 $\sup = 3 + 4 = 7 \le 10$ 이므로 이 행은 어떤 해에서도 깨지지 않습니다. 삭제해도 됩니다.

### 그런데 무조건 지우면 안 됩니다

논문 5.1절은 세 가지를 지적합니다.

1. **판정 자체가 어렵습니다.** 일반적인 redundancy 판정은 NP-complete입니다. 임의의 MIP에 비실현 행 $0 \le -1$ 을 붙이면, 이 행이 필요한지가 원래 문제의 실현 가능성과 같아지기 때문입니다.
2. **MIP에서 redundant여도 LP 완화에서는 쓸모가 있습니다.** 절단 평면(cut)이 바로 MIP-redundant 제약입니다. 정수 해를 하나도 자르지 않지만 LP 완화 영역을 조여 줍니다. 그래서 솔버가 지우는 것은 **LP 완화에서도 redundant인** 제약입니다.
3. **실험 결과도 이를 뒷받침합니다.** 선형 종속인 등식 행을 찾아 지우는 기능을 켰더니 오히려 성능이 약 4% 나빠졌습니다(10초 이상 구간). 노드 수도 같은 비율로 늘었습니다. 저자들은 이유를 완전히 이해하지 못했다고 쓰며, 중복 행이 cut 생성의 재료로 쓰이기 때문일 것이라는 가설만 제시합니다.

## 4. 경계 강화 (3.2절)

제약 $A_{iS}x_S + a_{ik}x_k \le b_i$ 에서 $S$는 $k$를 뺀 나머지 변수 집합입니다. 나머지 항의 최솟값을 $\ell_{iS} = \inf\{A_{iS}x_S\}$ 라고 하면, $a_{ik}>0$ 일 때

$$x_k \le \frac{b_i - A_{iS}x_S}{a_{ik}} \le \frac{b_i - \ell_{iS}}{a_{ik}}\quad\Rightarrow\quad u_k := \min\Big\{u_k,\ \frac{b_i-\ell_{iS}}{a_{ik}}\Big\}\qquad\text{(식 3.4)}$$

$a_{ik}<0$ 이면 하한을 같은 방식으로 올립니다(식 3.5). $x_k$가 정수 변수이면 내림(올림)해서 정수 경계로 만듭니다. 등식은 부등식 두 개로 나눠 처리합니다. 이 과정을 반복하는 것을 domain propagation이라고 합니다.

### 논문의 예제: 끝나지 않는 경계 강화

$$x_1 - a\,x_2 = 0,\qquad a\,x_1 - x_2 = 0\qquad(0<a<1,\ 0\le x_1,x_2\le 1)$$

첫 식으로 $x_1 \le a x_2$ 이고 $x_2 \le 1$ 이니 $x_1 \le a$ 입니다. 이 새 상한을 둘째 식에 쓰면 $x_2 = a x_1 \le a^2$ 이고, 이걸 다시 첫 식에 쓰면 $x_1 \le a^3$ 입니다. 계속하면

$$x_1 \le a^{2t-1},\qquad x_2 \le a^{2t}$$

이고 끝없이 작아집니다. 참값은 $x_1=x_2=0$ 하나뿐인데 경계는 거기에 한없이 다가가기만 합니다.

**직접 계산한 예 ($a=0.5$).** 두 식을 번갈아 적용한 결과입니다.

| 횟수 | 적용한 식 | 새 경계 | 이번에 줄어든 양 |
|---|---|---|---|
| 1 | 첫째 | $x_1 \le 0.5$ | 0.5 |
| 2 | 둘째 | $x_2 \le 0.25$ | 0.75 |
| 3 | 첫째 | $x_1 \le 0.125$ | 0.375 |
| 4 | 둘째 | $x_2 \le 0.0625$ | 0.1875 |
| … | … | … | … |
| 11 | 첫째 | $x_1 \le 0.000488$ | 0.00146 |
| 12 | 둘째 | ($x_2 \le 0.000244$) | 0.00073 → **갱신하지 않음** |

### 그래서 한도를 둡니다

Gurobi는 **연속변수** 경계를 다음 두 조건을 모두 만족할 때만 갱신합니다.

- 경계가 바뀌는 양이 $10^3\cdot\varepsilon$ 이상일 것 (기본 $10^{-3}$)
- 새 경계의 절댓값이 $10^8$ 미만일 것

또 한 번의 presolve 패스에서 각 제약에 경계 강화를 한 번만 적용해, 패스 수가 전체 작업 한도에 묶이게 합니다. 위 표에서 12번째가 $0.00073 < 10^{-3}$ 이라 멈추는 이유입니다. 정수 변수는 경계가 정수라서 한 번에 최소 1씩 움직이고 범위가 유한하므로 이런 무한 사슬이 생기지 않는다고 저는 이해했습니다(논문에 명시된 이유는 아니고 제 추론입니다).

효과는 끄면 10초 이상 구간에서 **1.09배**입니다. 저자들은 이 값이 낮은 이유로 다중 제약 경계 강화, probing, 노드 경계 강화가 같은 일을 겹쳐서 하기 때문이라고 봅니다.

## 5. 계수 강화와 Big-M (3.3절)

### 개념

계수 강화(coefficient strengthening)는 **정수 해 집합은 그대로 두고 LP 완화만 더 조이도록** 제약의 계수를 바꾸는 기법입니다. 논문은 "제약 $a x\le b$ 가 $a'x\le b'$ 를 dominate한다"를, 변수 경계 상자 안에서 앞의 LP 실행가능 영역이 뒤의 영역에 엄격히 포함되는 것으로 정의합니다.

### 식

$x_k$가 정수 변수이고 $A_{iS}x_S + a_{ik}x_k \le b_i$ 라고 합시다. 이번에는 나머지 항의 **최댓값** $u_{iS}$ 가 필요합니다(단일 제약에서는 $u_{iS}=\sup\{A_{iS}x_S\}$).

- $a_{ik}>0$, $u_k<\infty$ 이고 $a_{ik}\ge d := b_i - u_{iS} - a_{ik}(u_k-1) > 0$ 이면
  $$A_{iS}x_S + (a_{ik}-d)\,x_k \le b_i - d\,u_k\qquad\text{(식 3.6)}$$
- $a_{ik}<0$, $\ell_k>-\infty$ 이고 $-a_{ik}\ge d' := b_i - u_{iS} - a_{ik}(\ell_k+1) > 0$ 이면
  $$A_{iS}x_S + (a_{ik}+d')\,x_k \le b_i + d'\ell_k$$

### 기호를 읽는 법

| 기호 | 뜻 |
|---|---|
| $x_k$ | 강화할 정수 변수 |
| $A_{iS}x_S$ | 제약에서 $x_k$ 항을 **뺀 나머지** |
| $u_{iS}$ | 그 나머지 항의 최댓값. **제약 전체가 아닙니다** |
| $\ell_k$ | $x_k$의 하한. 이진 변수이면 0 |
| $d'$ | $x_k$가 하한보다 한 칸 위일 때 제약에 남는 여유 |

### Big-M에 적용 (직접 대입한 계산)

논문에 Big-M 예시가 있는 것은 아니고, 위 식에 대입한 계산입니다. 제약 $x - 10y \le 0$, $0\le x\le 4$, $y\in\{0,1\}$ 입니다. 즉 $M=10$, $x$의 실제 상한 $u=4$ 입니다.

- 강화할 변수는 $y$ ($k=y$) 이고 $a_{ik}=-10<0$, $b_i=0$, $\ell_k=0$ 입니다.
- 나머지 항은 $x$ 하나라서 $u_{iS}=\sup\{x\}=4$ 입니다.
- $d' = 0 - 4 - (-10)(0+1) = 6 > 0$, 조건 $-a_{ik}=10\ge 6$ 도 만족합니다.
- 새 제약: $x + (-10+6)\,y \le 0 + 6\cdot 0$, 즉 $x - 4y \le 0$ 입니다.

$M$이 10에서 실제 상한 4로 줄었습니다. $y$ 자체는 계속 0 또는 1이고, 음수여야 하는 것은 $y$의 **계수** $-M$ 입니다.

**정수 해는 그대로입니다.** $y=0$ 이면 두 제약 모두 $x\le 0$, $y=1$ 이면 원래는 $x\le 10$ 인데 $x\le 4$ 가 이미 있으니 $x\le 4$ 로 같습니다. **LP 완화는 조여집니다.** 원래는 $y\ge x/10$, 강화 후에는 $y \ge x/4$ 입니다. $x=4$ 에서 LP가 $y=0.4$ 까지 내려가던 것이 $y=1$ 로 올라갑니다.

$d'$ 가 양수가 되려면 $M>u$ 이어야 합니다. $M=u$ 이면 이미 가장 강한 형태입니다. 그래서 변수의 상한을 데이터로 계산해서 $M$으로 쓰는 것이 presolve가 해 줄 일을 줄여 줍니다.

효과는 끄면 1.06배로 작습니다. 이 역시 다중 제약 계수 강화(5.4절)와 probing이 일부를 겹쳐서 합니다.

## 6. Chvátal-Gomory 강화 (3.4절)

정수 변수만 있는 제약 $A_{i\cdot}x\ge b_i$ ($\ell=0$, 계수 비음수)에 대해, 스칼라 $s>0$ 을 찾아

$$\lceil a_{ij}s\rceil\cdot\frac{b_i}{\lceil b_i s\rceil}\le a_{ij}\ \ \forall j$$

가 성립하고 어떤 $k$ 에서는 엄격하게 성립하면 제약을 $\sum_j\lceil a_{ij}s\rceil x_j\ge\lceil b_is\rceil$ 로 바꿉니다. Gurobi는 $s$를 $\{1,\ t/a_{\max},\ t/a_{\min},\ (2t-1)/(2a_{\min})\ :\ t=1,\dots,5\}$ 에서 시도하는 간단한 휴리스틱으로 찾습니다.

논문은 이 기법의 효과가 "실망스럽다"고 씁니다. 끄면 10초 이상 구간에서 **1.00배**, 즉 차이가 없는데도 Gurobi 기본 설정에서 켜져 있습니다.

## 7. 이중 고정 (4.4절)

변수 $x_j$가 등식에 나오지 않고 ($\circ_i$ 가 $=$ 인 행에서 $a_{ij}=0$), 모든 제약이 $\le$ 형태일 때 목적계수와 제약 계수의 부호만으로 변수를 고정할 수 있습니다.

- 경우 (i): $c_j\ge0$ 이고 모든 $i$ 에서 $a_{ij}\ge0$ → $x_j := \ell_j$ (하한이 유한할 때)
- 경우 (ii): $c_j\le0$ 이고 모든 $i$ 에서 $a_{ij}\le0$ → $x_j := u_j$

변수를 키워서 좋을 것이 목적함수에도 제약에도 없으니 가장 작은 쪽에 둔다는 논리입니다.

### 논문의 Example 4: 치환

$$
\min\ x_1+x_2+x_3\quad\text{s.t.}\quad
\begin{cases}
2x_1+4x_2-3x_3\le 8 & (1)\\
-x_2-x_3\le -4 & (2)\\
-x_1-x_2+8x_3\le 0 & (3)
\end{cases}
\quad 0\le x_1,x_2\le 4,\ x_3\in\{0,1\}
$$

$x_1$은 제약 (3)에만 음의 계수로 나옵니다. $x_3=0$ 이면 (3)이 redundant라서 $x_1$을 0보다 크게 둘 이유가 없습니다. $x_3=1$ 이면 (3)에서 $x_1+x_2\ge 8$ 이라 $x_1=x_2=4$ 입니다. 그러므로 $x_1 := 4x_3$ 으로 **치환**할 수 있습니다.

> 이 예제는 치환 규칙을 보이기 위한 것이고, 세 제약을 동시에 만족하는 해는 없습니다. (2)에서 $x_2\ge3$, $x_3=1$ 이면 위에서 $x_1=x_2=4$ 가 되는데 이때 (1)의 좌변은 $8+16-3=21>8$ 이고, $x_3=0$ 이면 $x_2=4$ 로 (1)의 좌변이 $16$ 이상이라 역시 깨집니다. 제가 직접 확인한 것입니다.

### 논문의 Example 5: 상한 낮추기

$$\min\ x_1+x_2+x_3\quad\text{s.t.}\quad 2x_1+4x_2-3x_3\le 8,\ \ -x_2-x_3\le -4,\ \ -2x_1-2x_2+x_3\le 6,\quad 0\le x_1,x_2,x_3\le 10$$

$x_1$ 은 제약 (3)에서 음의 계수를 가집니다. $x_1=2$ 이면 (3)은 $-2\cdot2+\sup\{-2x_2+x_3\}=-4+10\le 6$ 으로 redundant가 됩니다. 그래서 $x_1\le 2$ 가 유효한 상한입니다.

효과는 끄면 1.04배이지만, 1,000초 이상 걸리는 213개 모델에서는 시간 25% 증가, 노드 31% 증가입니다. 어려운 모델에서 더 듣는 기법입니다.

| 기법 | 전체 | 영향받은 모델 |
|---|---|---|
| 모델 정리 (작은 계수 제거 등) | 1.10 | 1.11 |
| 경계 강화 | 1.09 | 1.11 |
| 계수 강화 | 1.06 | 1.08 |
| Chvátal-Gomory 강화 | 1.00 | 1.01 |
| 이중 고정·치환·경계 강화 | 1.04 | 1.06 |
| 대칭 변수 병합 | 1.03 | 1.36 |
| Orbital fixing | 1.20 | 1.77 |

- "단일 제약 reduction"은 3.1~3.7절처럼 **한 번에 제약 하나(와 변수 경계, 정수 조건)만** 보는 기법의 묶음입니다. 끈다는 것은 사용자 옵션이 아니라 저자들이 소스 코드를 고쳐서 꺼 본 실험입니다.
- 기법 하나씩은 작아도 합치면 9배가 넘습니다. 한 기법이 일으키는 변화가 다른 기법의 재료가 되기 때문이라고 읽었습니다.
- 대칭 관련 기법은 일부 모델에만 적용되지만 거기서는 큽니다. 자세한 내용은 [대칭성 글](../milp-symmetry/)에 있습니다.

## 9. 모델을 쓸 때 기억할 것

- 변수 경계를 정확히 써 줍니다. 활동량 계산이 경계에서 출발하므로, 경계가 느슨하거나 무한이면 redundant 판정도 계수 강화도 할 수 없습니다.
- Big-M은 데이터로 계산한 가장 작은 값으로 씁니다. presolve가 일부를 줄여 주지만 그것도 경계를 알아야 가능합니다.
- 모델을 단순하게 만들려고 redundant 제약을 직접 지울 때는 조심해야 합니다. cut의 재료가 될 수 있기 때문입니다.
